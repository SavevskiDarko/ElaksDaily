## Also required, and invisible to this script

- **Row-level security policies on every table above.** The app decides what
  each person sees in the browser, from `user_roles`; that is a convenience,
  not a boundary. Anyone signed in holds the anon key and can call the REST
  API directly, so the policies are the only real enforcement.
- **`user_roles` must not be self-editable.** The app inserts a row on first
  sign-in and the owner edits rows from the Team screen. An employee must not
  be able to set their own `role` to `owner`.
- **`secrets`** holds the Anthropic API key and must have no select policy —
  only `read-doc`, running as the service role, may read it. Written through
  `set_secret()` / `clear_secret()`.
- **Unique constraints on `offers.number` and `invoices.number`.** The app
  reads the highest and adds one; without the constraint two devices can
  produce two documents with the same number.
- **Storage buckets**, if photos are ever moved out of the `*_photos` and
  `*_images` tables.
